# Controlled V2 browser acceptance

These scripts are opt-in acceptance runs, separate from pytest discovery. They use Python Playwright with its installed Chromium, httpx and python-jose. Set VALORIA_E2E_BASE_URL and VALORIA_E2E_API_URL explicitly (defaults: loopback3003/8013), and optionally VALORIA_E2E_OUTPUT. Both services must be loopback and backed by a dedicated synthetic database. Never point them at a tunnel to production.

Run v2_browser_core.py, v2_browser_recovery.py, then v2_browser_sessions.py. Each exits nonzero for a failed scenario and saves results, screenshots and a trace. Browser core expects a fresh unread alert for synthetic user1; reset only that dedicated fixture between runs. Sessions temporarily removes a synthetic saved listing then restores it and checks user isolation. Recovery injects HTTP failures only for named error scenarios; ordinary flows use the actual API/database.

Fixture schema: migrate a fresh PostgreSQL database through0022. Seed candidate-a@example.test(admin), candidate-b@example.test(beta_user), candidate-empty@example.test(beta_user), password CandidateOnly123!, IDs1/2/3; listings1130/1131(canonical duplicate),298(removed, last_seen2026-06-05T16:23:39Z),3633(Portal MLC-4082793840),10000..10013 comparables. Users1/2 save1130/298/3633 and share unread price-drop alert1. Supply a clearly marked synthetic UF snapshot, a ready derived thumbnail for1130, and disabled scheduler/workers/on-demand refresh. The exact executed seed and environment are retained in the acceptance evidence folder. This is isolated test data, not a production seed command.

16 executed scenarios cover real authentication, alert acknowledgements/reload/user isolation, withdrawn/saved contracts, actual downloaded report, derived thumbnails, one-time Radar prefill, navigation, same/other-tab session clearing, saved-status failure/recovery,403/429/500/503 presentation, empty account, deletion/cancel, marker selection, and a correctly signed expired session. Invalid-token and signed-expiry checks are separate.
